👥 학생 명단 업로드

출전선수명단 서식(.xlsx)을 그대로 올리면 됩니다. 반별 파일 여러 개를 한꺼번에 선택해도 되고, 한 파일에 반별 시트로 넣어도 됩니다.
· 종목 칸에 O(또는 0, ○, V) 표시 = 출전 · 칸에 주장/후보라고 쓰면 역할까지 표시 · 환자 칸 표시 = 체크 제외
· 반은 서식 제목 1학년 ( 3 )반 → 시트 이름 3반 → 파일 이름 순으로 자동 인식 (실패 시 위 '반 지정' 사용)
· 불러온 내용은 아래 칸에 표준 목록으로 바뀌어 들어옵니다. 오타는 여기서 고친 뒤 업로드하세요.
